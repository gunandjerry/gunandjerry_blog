3. 세부 설정 패널 제작하기

세부 설정 패널 위젯 작성

이제 옵션 메뉴에서 특정 항목을 눌렀을 때 관련된 설정 항목들이 스크롤 박스 안에 나열되는 옵션 패널을 만들어보자.

예시로 범용적으로 쓸 수 있는 옵션 패널을 만들자.
UUserWidget WBP를 생성하고 이름은 S01_WBP_OptionPanel로 한다.

레이아웃

구조는 위와 같다. 최상위 Size Box에서 Width Override로 약 1000, Height Override로 약 550 정도의 크기를 주었고,
Vertical Box 아래의 Scroll Box의 Size는 Fill로 설정하여 맨 밑의 Reset, Apply, Back 버튼 위쪽을 모두 차지하게 했다.
최하단 버튼은 Common Border로 감싸서 이전에 만들었던 CommonBorderStyle을 지정해줬다.
최하단의 세 버튼은 CommonButton으로 역시 이전에 만든 CommonButtonStyle을 지정한다.

메인메뉴 위젯에 추가하기

이제 이 세부 옵션 패널들 각각도 WBP_MainMenu의 위젯 스위처 밑으로 들어갈 것이다.
아래와 같이 User Created 위젯을 추가해주면 된다.

문제는 이렇게 추가된 위젯에는 아직 노출된 이벤트 디스패치가 없기에 내부 엘리먼트와 바직접적으로 상호작용할 수 없다는 것.

OP_SampleOptionPanel의 Back 버튼을 눌렀을 때 다시 VB_Settings로 전환되어야 하므로, 우선 S01_WBP_OptionPanel에 PressBack 이벤트 디스패치를 추가하고 Back 버튼이 눌렸을 때 콜백한다.

이러면 메인메뉴 위젯에 추가된 OP_SampleOptionPanel에서 해당 이벤트가 노출된다.

이제 이전에 만들었던 것처럼 스위처 전환 로직을 추가해주면 된다.

노가다로 옵션마다 다 추가해주자.

옵션 항목 추가하기

이제 Scroll Box 안에 실제 옵션 항목들을 추가해보자. 타입에 따라 다양한 범용 위젯으로 만들 것이다. 실제로 설정을 적용하는 로직은 나중에 연결하겠다.

Cycle switch button

양쪽에 화살표를 두고 설정값을 변경하는 버튼 옵션을 만들어보자.

Common Rotator

UCommonRotator를 상속한 WBP를 생성하고 이름은 S01_WBP_OptionRotator으로 한다.
이 위젯은 간단히 텍스트 배열을 받고 인덱스를 통해 그 중 하나의 텍스트를 띄우는 역할을 수행한다. (이정도는 직접 만들어도 금방이지만, 이미 만들어둔 걸 쓰자.)

위젯을 생성하고 열어보면 MyText라는 UCommonText 위젯을 찾을 수 없어 바인딩에 실패했다는 오류가 뜬다.

대충 이런 구조로 만들어두고 Common Text 위젯의 이름을 MyText로 만들고 Variable 속성을 켜주자.
Common Text 위젯의 Overlay Slot의 가로 세로 정렬은 중앙으로, 추후 이 로테이터를 사용한 옵션 항목을 만들 때 위치 정렬을 맞춰주기 위해 Appearance - Min Desired Width는 200 정도로 넉넉하게 줘서 텍스트의 길이와 상관없이 정렬이 맞춰지도록 하자. (Min Desired Width 내에서도 중앙 정렬을 하려면 Appearance - Justification도 Center로 맞춰줘야 한다.)

텍스트 아래에 인덱스 비쥬얼 추가하기

필요하다면 텍스트 아래에 현재 몇 번 항목을 보고 있는지 시각적으로 알려주는 Pip(?)을 추가해볼 수 있다.
Common Text 위젯을 Vertical Box로 래핑(우클릭 -> Wrap with)한 뒤 그 밑에 추가할 것이다.

예시에서는 아래의 블록 이미지를 항목의 개수만큼 나열해서 만들어볼 것이다.

항목의 개수만큼 이미지를 추가해서 현재 인덱스에 따라 색이 다른 이미지로 교체해줘도 되지만, 이번에는 머터리얼을 사용해 좀 더 스마트하게 만들어보자.

새 머터리얼을 만들고 도메인은 User Interface, 블렌드 모드는 Transcluent로 설정한다.

우선 아래와 같이 노드를 구성한다.

텍스쳐의 UV를 읽을 때 X 방향으론 PipCount의 개수만큼 Step에 곱해서 읽는다. 그렇게 되면 예컨대 PipCount가 2일 때 텍스쳐를 X 방향으로 2번(UV는 초과되면 Wrap되어 0으로 돌아가므로) 읽는 셈이다.
따라서 예컨대 항목이 4개라면 아래와 같이 그려질 것이다.

이번엔 선택된 인덱스의 Pip만 그려지게 해보자. 그래프를 다음과 같이 확장한다.

뭔가 복잡해보이지만 단순한 로직이다.
Step 노드는 X가 Y보다 작을 때 0, 이상이면 1을 반환한다. 이걸 이용해 선택된(그려져야 하는) Pip의 시작부분 이전과 끝부분 이후를 날려버릴 것이다.

그 방법은 이렇다. 첫 번째 Step은 X를 선택된 Pip의 끝에 두어서 선택된 Pip까지 1을 뱉게 하고,
두 번째 Step은 선택된 Pop의 처음에 두어서 선택된 Pip의 이전까지만 1을 뱉게 한다.

이후 첫 번째 Step에서 두 번째 Step을 빼면 선택된 Pip 구간을 기준으로

  • 이전 구간: 1 - 1 = 0을 반환
  • 선택된 Pip 구간: 1 - 0 = 1을 반환
  • 이후 구간: 0 - 0 = 0을 반환
    하게 된다.

이제 이 값을 Alpha값과 곱해 Opacity로 사용하면 딱 선택된 Pip만 그려지게 된다.

하지만 선택되지 않은 Pip들도 다른 색상으로 그려지는게 보기 좋을 것이다. Subtract와 Multiply 사이에 Lerp 노드를 추가하고, Subtract 결과를 Alpha로, A는 약 0.4, B는 1.0으로 설정한다.

이렇게 되면 Subtract의 결과는 0 또는 1만 나오기 때문에 0이 나올 때는 0.4를, 1이 나올 때는 1을 반환하게 된다.

Note

이렇게 Lerp를 if 노드의 대안으로 사용하는 기법은 자주 사용되므로 익혀두자. if 노드는 Shader permutation을 생성하지만 Lerp는 단순 수식이라 셰이더의 복제가 일어나지 않는다.

항목(라인) 만들기

이번엔 UUserWidget을 상속한 WBP를 만들고 이름은 S01_WBP_OptionCycle로 한다.

구조는 위와 같다.

  • Common Border에는 이전의 Border Style을 넣어 스타일을 통일해준다.
  • Horizontal Box를 두고 가장 먼저 Common Text를 넣어 항목 이름을 적는다.
  • 그 다음 Spacer를 넣고 Size를 Fill로 설정하여 조작버튼이 우측으로 정렬되게 한다.
  • 이후 이전에 만든 S01_WBP_MenuButton을 양쪽에, 그 사이에 S01_WBP_OptionRotator를 넣는다.

양쪽의 <<, >> 버튼을 누르면 Rotator의 인덱스를 바꿔 전환시킬 것이다.

Pre Construct 이벤트에서 Common Rotator를 초기화하자.

Populate Text Labels 함수로 Common Rotator에 항목 리스트를 지정하고, Set Selected Item 함수로 그 중 n번째 항목을 지정해 출력한다.

이후 좌우 버튼의 Click 이벤트를 등록한다. Common Rotator의 Shift Text 함수를 사용하자.
