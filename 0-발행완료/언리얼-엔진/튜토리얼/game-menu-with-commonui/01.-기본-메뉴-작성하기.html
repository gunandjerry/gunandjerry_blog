1. 기본 메뉴 작성하기

이번 챕터의 완료 화면 미리보기

시작하기

이 튜토리얼은 CommonUI를 사용해 게임 메뉴를 만드는 과정을 다룬다.

첫 번째 챕터에선 간단하게 메인 메뉴의 레이아웃을 구성한다.

준비하기

당장 CommonUI의 사용법을 배우지는 않겠지만, 추후 사용할 예정이므로 CommonUI 플러그인을 활성화한다.

메인 메뉴의 백그라운드로 사용할 이미지도 구하도록 하자.

메인메뉴 위젯 작성하기

위젯 생성

UUserWidget BP를 생성하고 이름은 S01_WBP_MainMenu으로 한다.

위젯의 하이어라키는 아래와 같이 구성할 것이다.

Canvas Panel은 절대 좌표로 자식 엘리먼트들을 배치하기 위한 패널이다. 그 밑에 배경을 채울 배경 이미지와 메인메뉴 버튼들이 들어갈 Vertical Box를 추가한다.

Canvas Panel이 루트 엘리먼트라 이 위젯이 Viewport에 부착될 경우 뷰포트의 크기를 따르게 되므로, 백그라운드 이미지의 Canvas Slot의 Anchor는 Fill(Min: 0, 0 / Max: 1, 1)로 설정하여 전체 화면을 채우도록 한다.

버튼 디자인

CommonUI의 CommonButtonBase BP를 생성하고 이름은 S01_WBP_MenuButton으로 한다.

CommonButtonBase는 CommonUI에서 사용하는 버튼의 기본형으로, CommonButtonStyle이라는 스타일 클래스를 사용해 아래와 같은 설정을 할 수 있다.

  • 버튼의 최대, 최소 크기
  • 기본 상태, 커서가 호버된 상태, 눌린 상태일 때 각각 다른 디자인을 적용 (텍스트에 대해서도 CommonTextStyle을 통해 다르게 지정 가능)
  • 각 상태마다 사운드 재생

버튼 레이아웃 디자인

버튼은 간단하게 Overlay를 루트로 두고 그 밑에 텍스트를 하나 추가할 것이다.
Overlay 위젯은 여러 엘리먼트를 겹쳐서 놓을 때 사용한다.

그리고 BP Graph에서 버튼 텍스트와 버튼 정렬 방식을 설정하여 Pre Construct (위젯이 생성될 때 Construct보다 먼저 호출 / 에디터에서 다른 위젯에서 사용될 때 최초로 또는 설정값이 바뀌었을 때마다 호출됨)에서 적용하게 했다. 중요한 건 아니니 대충 넘어간다.

Note

Get Slot -> Cast To OverlaySlot 대신 Slot as OverlaySlot Pure 노드로 바로 캐스팅해서 가져올 수 있다. 단 Pure 노드인 만큼 연결된 핀의 수만큼 캐스팅을 수행함에 주의.

Style 입히기

CommonButtonBase BP의 Details에서 Style 슬롯의 + 버튼을 누르거나 CommonButtonStyle BP를 생성한다. 이름은 S01_CommonUIStyle_MenuButton으로 한다.

지금은 간단하게 기본 상태일 땐 글자만 출력되게 하겠다. Normal -> Normal Base -> Tint -> A 값을 0으로 바꾼다.
저장한 뒤 CommonButtonBase BP의 Details - Style 슬롯에 제대로 장착되었는지 확인하자.

Note

버튼 안에 있는 텍스트로 UTextBlock 대신 UCommonText를 사용하면, 마찬가지로 UCommonTextStyle을 만들어 끼움으로서 간단하게 스타일을 지정할 수 있다.

버튼 배치하기

이제 메인 메뉴 위젯의 VerticalBox에 버튼들을 배치하고 적당히 커스텀한다.

HUD로 띄우기

메인 메뉴는 간단하게 Title용 GameMode와 해당 GameMode에서 사용할 HUD를 사용하여 띄워보도록 하겠다.
HUD BP를 생성한다. HUD BP는 엔진에 의해 시작과 동시에 생성되는 액터이다.

간단하게 BeginPlay에서 메인메뉴 위젯을 생성하고, 뷰포트에 부착하고, 인풋 모드를 바꾸고, 커서를 보이게 설정한다.

이후 타이틀용 게임모드에 장착하고 게임모드를 레벨의 GameMode Override에 장착한 뒤 게임을 시작해보면 메인메뉴가 뜨는 것을 확인할 수 있다.
