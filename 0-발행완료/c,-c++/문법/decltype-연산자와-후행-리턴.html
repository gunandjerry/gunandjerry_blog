decltype 연산자와 후행 리턴

decltype(식)

식별자 표현식의 타입을 '원본 그대로' 보존해 해당 타입으로 전치되는 예약어.
auto랑 마찬가지로 컴파일 타임에 타입을 추론하므로 컴파일 추론 규칙에 부합해야 한다.
다음은 그 예시다.

int a = 3;
decltype(a) b = 2; // int b = 2;

int& r_a = a;
decltype(r_a) r_b = b; // int& r_b = b;

int&& x_a = 3;
decltype(x_a) x_b = 2; // int&& x_b = 2;

struct Foo { double b; };
Foo* foo;
decltype(foo->b) bb = 0.1; // double bb = 0.1;

auto와의 차이

auto는 사실 타입을 정확하게 추론하진 못 한다. auto는 참조자 속성과 const 속성을 마음대로 지워버리고, 배열을 암시적으로 포인터로 변환해버린다.
반면 decltype은 타입을 있는 그대로 추론한다. 즉 밸류 카테고리, const 속성, volatile 속성, 참조성까지 모두 보존한다.

뿐만 아니라 템플릿 함수와 함께 쓰일 때 진가가 드러난다. 템플릿 함수에선 어떤 객체의 타입이 템플릿 인자들에 의해서 결정되는 경우가 있다. 예를 들어서 아래와 같은 함수를 생각해보자.

template <typename T, typename U>
void add(T t, U u, /* 무슨 타입이 와야 할까요? */ result) {
  *result = t + u;
}

위 코드에서 result 변수의 타입은 T, U에 의해 결정된다. 이 때 decltype을 사용하면 이걸 컴파일 타임에 자동으로 추론해준다.

template <typename T, typename U>
void add(T t, U u, decltype(t + u)* result) {
  *result = t + u;
}

추론 규칙

괄호로 둘러쌓이지 않은 식별자 표현식

소괄호로 쌓이지 않은 식별자 표현식을 전달할 경우 식별자 표현식의 결과로 도출되는 타입을 그대로 추론한다.

Note

식별자 표현식은 쉽게 말해 어떤 연산을 수행하지 않고 단순히 하나의 타입으로 귀결되는 식을 의미한다.

그 외의 경우

식별자 표현식이 괄호로 쌓였다거나, 기타 다른 경우엔 값의 종류에 따라 밸류 카테고리를 결정한다. (const, volatile 속성 등은 별개로 보존)

  1. 값의 종류가 X-Value -> T&&
  2. 값의 종류가 L-Value -> T&
  3. 값의 종류가 PR-Value -> T

이런 규칙이 있기 때문에 괄호의 유무가 가장 미묘한 차이가 된다.

int x;
decltype(x) x1;
decltype((x)) x2;

위 코드에서, x1은 식 x로부터 int 타입으로 추론되고,
x2는 식 (x)로부터 int& 타입으로 추론된다. (따라서 초기화와 동시에 대상을 참조하지 않고 있으므로 에러가 발생)

전자는 괄호 없는 식이므로 식에서 귀결된 타입인 int를 그대로 사용한 것이고, 후자는 '그 외의 경우'에 해당하므로 L-value인 x로부터 참조성을 보존한 것이다.

decltype의 특수한 활용

후행 반환 형식(Trailing return type)과 decltype

후행 반환 형식은 반환 타입을 추론하기 위해 반환 타입을 본문을 검사한 이후에 결정하도록 하는 것을 말한다. C++11에서 도입됐다.
독특한 문법을 사용한다.

먼저 후행 반환 형식 문법을 모르는 상태에서 반환 타입을 추론하고 싶다고 하자.

template <typename T, typename U>
decltype(t + u) add(T t, U u) {
  return t + u;
}

아마 이런 식으로 썼겠지만, 이 코드는 오류가 난다. t, u라는 매개변수의 정의가 decltype(t + u) 부분 이후에 나오기 때문에 t, u의 정체가 무엇인 지 알 수 없기 때문이다.
이 때문에 C++11에서 함수의 리턴타입을 마지막에 결정할 수 있게 하는 문법이 추가되었다.

// 'auto 함수명(인자) -> 후행반환타입'의 꼴
template <typename T, typename U>
auto add(T t, U u) -> decltype(t + u) {
  return t + u;
}

decltype(auto)

C++14에서 추가된 편의성 문법. 담기는 값에 따라 타입을 알아서 (+ decltype처럼 원본 성질 그대로) 추론한다. decltype + auto라고 보면 된다.

int x = 10;
int& ref_x = x;

auto y1 = ref_x; // int, auto는 참조성을 제거한다.
decltype(ref_x) y2; // int&, decltype은 식의 타입을 원본 그대로 보존하여 추론한다.
decltype(auto) y3 = ref_x; // int&, decltype(auto)는 담긴 값의 타입을 원본 그대로 보존하여 추론한다.

C++14부터 후행 리턴 형식에서도 후행 리턴을 쓰지 않고 그냥 반환 타입에 decltype(auto) 또는 auto를 쓰는 게 가능해졌다.

// 기존의 후행 리턴 타입
template <typename T, typename U>
auto add(T t, U u) -> decltype(t + u) {
  return t + u;
}

// C++14부터 허용
template <typename T, typename U>
decltype(auto) add(T t, U u) {
  return t + u;
}

// 그냥 auto도 쓸 수 있게 됨. 이 때는 auto의 추론 규칙을 따른다.
template <typename T, typename U>
auto add(T t, U u) {
  return t + u;
}
