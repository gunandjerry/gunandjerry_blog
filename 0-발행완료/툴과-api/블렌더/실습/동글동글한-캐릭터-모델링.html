동글동글한 캐릭터 모델링

병아리

대칭 캐릭터이므로 Loop cut으로 반을 날리고 Mirror를 추가한다.

미러의 Clipping을 체크하면 미러가 생성되는 축 방향으로는 점이 움직이지 않게 되어 구멍이 뚫리는 등의 불상사가 생기지 않는다.

큰 특징부터 구현한다. 상단의 면 크기를 줄여 사다리꼴로 만든다.

상단, 하단의 여섯 엣지를 누르고 베벨을 적용하여 경사를 만든다.

오브젝트 모드 → Add Modifier → Generate → Subdivision Surface

levels viewport 레벨을 올려 동글동글한 모양을 만들자.

에디트 모드로 돌아가보면 원래 데이터를 바탕으로 서브디비전 페이스를 조절할 수 있게 되어있다.
서브디비전을 적용할 경우 각 또는 vertex가 사라지는데, 이 때 예리한 각을 만들고 싶다면 Edge에 대해 Bevel을 적용한다.

Add → Mesh → UV Sphere를 추가하고 Segment, Ring을 4, 4 정도로 설정해 깃처럼 배치한다.

거기에 Subdivision surface를 추가하고 적당히 배치한다.

아이스크림


몸통 만들기(Mirror 이용 대칭) → 하체 Extrude로 만들기

몸통 형상을 잡고, Mirror를 적용하기 위해 반을 자르고 Mirror 모디파이어를 적용한다.

이 때 큐브의 모양을 바꿨다면, 좌측 상단 OBject→ Apply → All transform을 적용하여 블렌더가 변경된 형상을 인식할 수 있게 한다.
Mirror의 Clipping 체크박스에 체크하면 미러의 접합부 버텍스들이 고정되어 떨어지지 않게 된다.

Subdivision Surface 모디파이어를 적용하여 둥근 모서리를 만든다. Level Viewport는 5 정도

바깥쪽 엣지를 고르고 베벨을 살짝 입혀서 각지게 만든다

마찬가지로 옆면 엣지에도 베벨을 입힌다.

상단의 버텍스만 잡은 채 크기를 줄여 내려갈 수록 작아지게 만든다.

하체를 만들기 위해 미러를 Apply로 적용하고, Loop cut으로 반을 가른다.

나이프로 루프 컷 엣지를 이용해 모양을 만든다.

이 때 부드러운 곡선 효과는 subdivision 모디파이어로 줄 수 있으니 선을 너무 분할하지 말고 각지게 자른다.

면의 엣지(또는 각)이 5개 이상이 되지 않도록 나이프 툴로 면을 나눠 정리해준다.


모든 면의 엣지는 4개 이하가 되어야 한다.

하체 영역을 선택하고 Extrude 툴로 빼낸다.

하체 부분에 유려한 각을 주기 위해 튀어나온 영역의 면을 선택하고 베벨을 입힌다.
선택할 때는 Subdivision의 모니터 아이콘을 꺼서 안 보이게 한 후 선택하자.

튀어나온 면의 안쪽, 바깥쪽 엣지에 대해 적용한다.

베벨이 얇을 수록 각이 강하게 나타난다.

손을 만들기 위해 팔이 있는 부위를 나이프로 나눠주고

subdivision 효과를 고려하면서 팔이 될 면을 만든다.

외부 면의 엣지가 5개가 되지 않도록 주의한다.

이제 Extrude로 팔을 뽑는다.

팔의 시작 엣지 부분에 베벨을 입혀서 팔의 굵기가 일정해지도록 각을 넣는다.


팔에 곡선을 주기 위해 팔을 루프컷으로 가르고, 바깥쪽 버텍스들을 아래로 내린 뒤 바깥쪽 버텍스와 중간 버텍스들을 적절히 회전시킨다.

팔의 굵기를 늘리고 싶다면 Individual Origin을 설정해 각각의 좌표를 유지한 상태로 팔의 엣지를 키운다.

다리를 만든다. 팔과 똑같이 나이프로 다리가 될 면을 만들고, Extrude로 뽑는다.

얼굴을 만든다.

나이프로 입 모양을 만들고 Extrude로 집어넣는다.


베벨을 입혀서 각을 준다.

눈이나 눈썹, 하체에 붙은 작은 초콜릿 알갱이 등 본체에서 빼내기 귀찮은 부분들은 그냥 외부에서 만들어서 붙인다.
