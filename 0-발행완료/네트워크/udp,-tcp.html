UDP, TCP

UDP

User Datagram Protocol.
데이터를 데이터그램 단위로 처리하는 비연결형 통신 규약. 호스트간의 연결도, 송수신하겠다는 신호 전달도, 패킷의 분할과 재조립도, 순서 정렬도 존재하지 않는다. 그냥 일정한 크기의 데이터그램 단위로 데이터를 꼴릴 때 보내고 온 게 있으면 받는 게 전부다.
따라서 TCP보다 훨씬 빠르지만 신뢰성을 보장할 수 없다. 그래서 실시간 스트리밍같은 속도가 최우선인 분야에서만 사용한다.
전송되는 데이터그램의 단위는 65535바이트로, 그보다 큰 데이터는 쪼개져서 보내지는데, 이 때 순서를 보장할 수 없으므로 주의해야 한다.

특징

  1. 연결 자체가 없으므로 서버 소켓과 클라이언트 소켓의 구분이 없다.
  2. IP와 PORT로만 송수신한다.
  3. 서버와 클라이언트는 1:1, 1:N, N:M으로 연결될 수 있다.
  4. 흐름제어가 없어 패킷이 제대로 전송되었는지는 알 수 없다.

TCP

Transmission Control Protocol.
일반적으로 TCP/IP로 묶여 불리는, 인터넷의 가장 기본이 되는 프로토콜. IP가 데이터의 송수신지를 담당한다면, TCP는 전달되는 패킷의 추적과 관리를 담당한다.
TCP는 과정을 통칭하는 추상적인 명칭일 뿐 TCP가 담당하는 패킷 전송을 위한 최적의 경로 배정(라우팅), 핸드셰이킹을 통한 데이터 무결성 보장, 패킷 통신의 혼잡제어 등등 여러 세부적인 기능들은 각각 구체적인 하드웨어 등을 통해 구현된다.
연결과정과 무결성 보장 과정이 추가되므로 UDP보다 훨씬 느리다.

특징

  1. 서버 소켓(흔히 Listen socket이라고 함)은 연결을 관리하며, 클라이언트 소켓은 서버에 연결을 요청, 허락받으면 경로가 이어진다.
  2. 서버와 클라이언트는 1:1로 연결된다.
  3. 고정된 데이터 단위가 아닌 스트림 전송 방식을 사용하여 패킷을 연속적으로 주고받는다. 이론적으로 그 크기는 무한이나, 실제로는 하드웨어의 송수신 버퍼가 가득 차면 더이상 패킷을 주고받을 수 없다.
  4. 따라서 TCP 서버는 지속적으로 NIC의 버퍼를 비워주는 것이 중요하다. 그래서 보통 어플리케이션단에서 링 버퍼(환형 큐)를 두고 버퍼에 있는 데이터를 옮기는 작업이 추가된다. 이건 지속적으로 NIC의 버퍼를 비워 제 때 제 때 수신을 받기 위함이기도 하고, 크기가 매우 큰 데이터가 들어오면 NIC 버퍼에 한 번에 담길 수 없기 때문에 하나의 온전한 데이터로 취급할 수 있을 때까지 더 큰 공간에 옮겨 담아야하기 때문이기도 하다.
  5. 손실된 패킷에 대해선 재전송을 요청하고 기다려야 하므로 실시간 서비스에는 사용하기 어렵다.

뭘 써야 하는가?

일반적으로 TCP 통신은 실시간 멀티플레이 게임에 사용하기는 너무 느리다. 서버의 성능이 매우 뛰어나고 최적화가 잘 됐다면 불가능한 건 아니지만, 일반적으론 UDP를 사용한다.
그러나 UDP는 신뢰성이 떨어지기 때문에 대부분의 게임 회사들은 자체적으로 데이터 무결성을 검사하여 '신뢰할 수 있는 UDP (Reliable UDP)' 시스템을 구축해서 사용하는 편이다.
Reliable UDP는 송수신 데이터를 기본적으로 두 가지로 구분한다. 하나는 대충 손실이 있어도 상관 없는 데이터, 다른 하나는 절대로 손실이 발생하면 안 되는 데이터다. 전자라면 대충대충 넘어가고, 후자라면 재전송하고 기다리도록 하는 방식.

UDP

UDP 서버

UDP 서버는 자신의 포트 번호, 리슨 소켓 핸들만 들고 있으면 된다. 이 예시는 가장 간단한 형태로 구현한 것이다.

#pragma once
#include <iostream>
#define WIN32_LEAN_AND_MEAN
#include <Windows.h>
#include <WinSock2.h>

#pragma comment(lib, "ws2_32.lib")

using uint = unsigned int;

class UDPServer
{
	uint port;
	SOCKET listen_socket_handle;
	WSADATA wsaData;
public:
	UDPServer(uint port, bool enable_blocking)
	{
		this->port = port;


		// 윈소켓 초기화 :: WSAStartup 함수에 버전 정보를 넣어 윈소켓 dll을 초기화한다.
		// 첫 번째 매개변수에 사용할 윈소켓 버전을 설정. 16비트를 8비트로 끊어서 앞이 주버전, 뒤가 부버전.
		// 두 번째 매개변수엔 WSADATA 구조체 포인터가 들어가는데, 초기화된 윈소켓 정보가 담긴다.
		int result = WSAStartup(MAKEWORD(2, 2), &wsaData);
		if (result != NO_ERROR) return; // 정상적으로 초기화됐으면 0(NO_ERROR) 반환


		// 윈소켓 커널 객체를 생성한다. 첫 번째는 주소 체계, 두 번째는 소켓이 데이터를 다루는 방법, 세 번째는 통신 프로토콜.
		// UDP를 사용할 것이므로 데이터 다루는 방식은 데이터그램으로, 통신 프로토콜은 UDP로 설정.
		listen_socket_handle = socket(PF_INET, SOCK_DGRAM, IPPROTO_UDP);
		if (listen_socket_handle == INVALID_SOCKET)
		{
			result = WSAGetLastError(); // 윈소켓을 다루다 오류가 발생했으면 WSAGetLastError()를 호출해 마지막 에러 코드를 반환받을 수 있으니 참고. 앞으로는 생략한다.
			return;
		}


		// ioctlsocket (i/o control socket) 함수로 소켓 설정을 바꿀 수 있다.
		// 마지막에 0을 넣으면 리시브할 때 블록킹 모드(수신을 받을 때까지 대기), 1이면 넌블럭킹(수신이 없어도 통과)
		unsigned long socket_type = 1;
		if (enable_blocking) socket_type = 0;
		result = ioctlsocket(listen_socket_handle, FIONBIO, &socket_type);
		if (result != NO_ERROR) return;


		// 소켓과 특정 주소, 포트를 바인딩
		SOCKADDR_IN server_address{};
		server_address.sin_family = AF_INET; // 참고로 PF는 프로토콜 패밀리, AF는 어드레스 패밀리인데, 사실상 같은 값이다.
		server_address.sin_port = htons(port); // 포트 번호를 빅 엔디안으로 변환 (네트워크에선 빅 엔디안만 사용하기 때문)
		server_address.sin_addr.S_un.S_addr = htonl(INADDR_ANY); // 서버가 어떤 IP와 바인딩되느냐를 결정. INADDR_ANY(0.0.0.0)는 현재 시스템에서 모든 사용 가능한 네트워크 인터페이스가 전부 클라이언트의 송신을 받을 수 있다는 의미임. 예컨대 LAN카드와 WI-FI 네트워크 인터페이스가 있으면 둘 다 받을 수 있다는 뜻. 만약 여기에 특정한 주소를 입력하면 그 주소를 가진 네트워크 인터페이스로만 받을 수 있음.

		// bind() 함수로 주소와 소켓을 바인딩할 수 있다. 참고로 std::bind랑 이름이 같아서 using namespace std 쓰면 충돌 난다...
		result = bind(listen_socket_handle, (SOCKADDR*)&server_address, sizeof(server_address));
		if (result == SOCKET_ERROR) return;
	}
	~UDPServer()
	{
		closesocket(listen_socket_handle);
		WSACleanup();
	}


	void Receive()
	{
		// UDP는 비연결 지향 소켓(SOCK_DGRAM)에서 클라이언트에게 받은 데이터그램을 가져와 버퍼에 담는 recvfrom() 함수를 사용. 이 때 필요하다면 클라이언트의 주소를 얻을 수 있음.
		char buffer[1000];
		SOCKADDR client_address;
		int client_address_size = sizeof(SOCKADDR); // 이 변수에는 recvfrom에 전달할 땐 초기 클라이언트 주소 구조체의 크기가 담겨있어야 하고, 반환될 땐 실제 클라이언트 주소 구조체의 크기가 담겨서 반환된다. 이는 클라이언트가 어떤 주소 체계를 사용하는지 모르기 때문. 예컨대 IPv4와 IPv6의 크기는 다르다.
		// 데이터그램을 가져오는데 성공했다면 result에 가져온 바이트의 크기가 담기고, 아니면 SOCKET_ERROR(-1)이 반환된다.
		int result = recvfrom(listen_socket_handle, buffer, 1000, 0, &client_address, &client_address_size);
		if (result > 0)
		{
			int last_index = min(result, 999);
			buffer[last_index] = '\0';
			std::cout << buffer << std::endl;

			// 간단한 에코 테스트
			SendBack(buffer, last_index, client_address);
		}
		else if (result == SOCKET_ERROR) return;
	}


	void SendBack(char* buffer, int last_index, SOCKADDR& client_address)
	{
		// UDP는 보낼 주소를 수동으로 입력하는 sendto() 함수를 사용한다.
		// sendto는 보내는데 성공(상대가 받았는지는 몰?루. 아무튼 내가 보냈으면 성공이다.)하면 보낸 바이트를, 아니면 SOCKET_ERROR(-1)를 반환한다.
		int result = sendto(listen_socket_handle, buffer, last_index, 0, &client_address, sizeof(client_address));
		if (result == SOCKET_ERROR) return;
	}
};

UDP 클라이언트

UDP 클라이언트는 UDP 서버보다 할 게 없다. 서버의 경우엔 특정한 주소와 포트로 바인딩해서 OS가 어떤 주소(즉, 어떤 네트워크 인터페이스와 포트)를 수신지로 쓸 수 있는지 알려줘야 했지만, 클라이언트는 일반적으로 그럴 필요가 없다. 왜냐면 클라이언트가 서버와 통신을 시도할 떄 OS가 임의로 사용 가능한 네트워크 인터페이스의 주소와 포트로 발신해주기 때문이다. 만약 서버로부터 에코를 받을 때도 전달했던 주소와 포트로 돌려받기 때문에 그냥 recvfrom()을 쓰면 OS가 가져와준다. (물론, bind를 하면 안 된다는 말은 아니다.)

#pragma once
#include <iostream>
#define WIN32_LEAN_AND_MEAN
#include <Windows.h>
#include <WinSock2.h>

#include <string> // 귀찮으니깐 주소 문자열로 적고
#include <WS2tcpip.h> // 여기 있는 함수로 변환할 거임

#pragma comment(lib, "ws2_32.lib")

using uint = unsigned int;

class UDPClient
{
	SOCKET client_socket_handle;
	WSADATA wsaData;
public:
	UDPClient()
	{
		int result = WSAStartup(MAKEWORD(2, 2), &wsaData);
		if (result != NO_ERROR) return;


		client_socket_handle = socket(PF_INET, SOCK_DGRAM, IPPROTO_UDP);
		if (client_socket_handle == SOCKET_ERROR) return;
	}
	~UDPClient()
	{
		closesocket(client_socket_handle);
		WSACleanup();
	}


	void Send(std::string server_ip, uint server_port, std::string message)
	{
		SOCKADDR_IN server_address{};
		server_address.sin_family = AF_INET;
		server_address.sin_port = htons(server_port);
		// 문자열로 된 주소를 sin_addr 형태의 주소로 변환해주는 함수
		int result = inet_pton(AF_INET, server_ip.c_str(), &(server_address.sin_addr));
		if (result == SOCKET_ERROR) return;


		char buffer[1000];
		int last_index = min(message.length(), 999);
		strcpy_s(buffer, 1000, message.c_str());
		buffer[last_index] = '\0';


		result = sendto(client_socket_handle, buffer, last_index, 0, (SOCKADDR*)&server_address, sizeof(server_address));
		if (result == SOCKET_ERROR) return;
	}
	void Receive(std::string server_ip, uint server_port)
	{
		SOCKADDR_IN server_address{};
		server_address.sin_family = AF_INET;
		server_address.sin_port = htons(server_port);
		int result = inet_pton(AF_INET, server_ip.c_str(), &(server_address.sin_addr));
		if (result == SOCKET_ERROR) return;
		int server_address_size = sizeof(SOCKADDR);


		char buffer[1000];

		result = recvfrom(client_socket_handle, buffer, 999, 0, (SOCKADDR*)&server_address, &server_address_size);
		if (result > 0)
		{
			int last_index = min(result, 999);
			buffer[last_index] = '\0';
			std::cout << buffer << std::endl;
		}
		else if (result == SOCKET_ERROR) return;
	}
};

TCP

TCP로 가면 좀 복잡해진다. 우선 호스트간에 연결하는 과정이 추가되고, 서버는 연결된 호스트들을 관리하면서 클라이언트로부터 메세지를 보냈다는 신호를 받으면 해당 클라이언트의 수신 스트림 버퍼에서 데이터를 꺼내서 확인하고, 데이터그램 단위로 수신되는 게 아니라 패킷으로 잘게 쪼개져서 보내지기 때문에 데이터가 완성되었는지도 확인하고 아직 오는 중이면 지나쳐야 한다.
뿐만 아니라 위에서 서술했듯이 링버퍼를 두고 NIC의 수신 버퍼를 비워가며 완성된 데이터 단위로 취급하는 과정도 추가되어야 한다. 예컨대 상대가 1GB의 파일을 보냈다면, 250mb만 받아서는 열 수 없다. 반드시 1gb 전부 받은 뒤 열 수 있는데, 그렇기 때문에 연속적으로 들어오는 스트림 방식의 데이터들을 저장해둘 공간이 필요하다고 생각하면 된다. (물론, 정말로 큰 데이터는 램에 있는 링 버퍼가 아니라 보조저장장치에 기록해서 저장하게 되지만, 이건 나중의 얘기.)

Ring Buffer

먼저 TCP 통신에 필수적인 링 버퍼를 설계해보자. 기본적으로 환형 큐와 딱히 다를 건 없다.

RingBuffer.h

#pragma once
#define WIN32_LEAN_AND_MEAN
#include <iostream>
#include <Windows.h>
#include <WinSock2.h>
#include <string>

using uint = unsigned int;

class RingBuffer
{
	char* buffer;
	const uint buffer_size;
	const uint real_buffer_size;

	uint front{ 0 }; // 담긴 영역의 머리
	uint rear{ 0 }; // 담긴 영역의 마지막 + 1
public:
	RingBuffer(uint buffer_size);
	~RingBuffer();

public:
	bool IsEmpty();
	bool IsFull();
	uint GetBufferSize();
	uint GetOccupiedSize();
	uint GetFreeSize();

private:
	uint GetFreeSizeContinuousFromRear();
	uint GetOccupiedSizeContinuousFromFront();

public:
	bool Receive(SOCKET socket); // NIC의 수신 버퍼에 있는 모든 데이터를 가져와서 buffer에 담는다.
	bool Read(char* dest, uint length); // length만큼 읽어서 dest에 담는다.
	bool Peek(char* dest, uint length); // length만큼을 읽을 수 있는지 확인한다. 읽을 수 있다면 dest에 담고 true를 반환한다.
};

RingBuffer.cpp

#include "RingBuffer.h"

RingBuffer::RingBuffer(uint buffer_size) : buffer_size(buffer_size), real_buffer_size(buffer_size)
{
	// 꽉 찼을 때도 rear를 위한 빈 공간이 필요하므로 + 1
	buffer = new char[real_buffer_size];
}

RingBuffer::~RingBuffer()
{
	if (buffer) delete[] buffer;
}

bool RingBuffer::IsEmpty()
{
	if (front == rear) return true;
	return false;
}

bool RingBuffer::IsFull()
{
	if (front == (rear + 1) % real_buffer_size) return true;
	return false;
}

uint RingBuffer::GetBufferSize()
{
	return buffer_size;
}

uint RingBuffer::GetOccupiedSize()
{
	if (IsEmpty()) return 0;
	if (front < rear) return rear - front;
	if (rear < front) return (buffer_size - front) + rear;
}

uint RingBuffer::GetFreeSize()
{
	return buffer_size - GetOccupiedSize();
}

uint RingBuffer::GetFreeSizeContinuousFromRear()
{
	if (front == rear) // 버퍼가 비어있는 경우
	{
		if (rear == 0) return buffer_size; // 맨 마지막에 rear를 위한 빈 공간 필요
		else return buffer_size - rear + 1; // rear를 위한 빈 공간이 필요하지 않으므로 +1
	}
	else if (front < rear)
	{
		if (front == 0) return buffer_size - rear;
		else return buffer_size - rear + 1; // rear를 위한 빈 공간이 필요하지 않으므로 +1
	}
	else if (rear < front) return front - rear - 1;
}

uint RingBuffer::GetOccupiedSizeContinuousFromFront()
{
	if (front == rear) return 0;
	else if (front < rear)
	{
		return rear - front;
	}
	else if (rear < front)
	{
		return buffer_size - front + 1;
	}
}

bool RingBuffer::Receive(SOCKET socket)
{
	if (IsFull())
	{
		printf("buffer is full.\n");
		return false;
	}

	// 버퍼가 다 차지 않았다면 최소한 1이 나옴.
	uint free_size = GetFreeSize();
	uint free_size_continuous = GetFreeSizeContinuousFromRear();

	int result = recv(socket, buffer + rear, free_size_continuous, 0);
	if (result == SOCKET_ERROR)
	{
		result = WSAGetLastError();
		if (result == 10035) return true; // 읽을 데이터가 없음.
		printf("failed to receive.\n");
		return false;
	}


	// 읽은 길이가 남은 길이보다 작다 -> rear만 이동시키고 종료
	if (result < free_size_continuous)
	{
		rear += result;
		return true;
	}
	// 읽은 길이가 남은 길이와 같다 -> 더 읽어야 할 수 있으므로 회전 후 다시 읽기
	else if (result == free_size_continuous)
	{
		if (free_size == free_size_continuous) // 가득 참
		{
			rear += result;
			return true;
		}

		rear = 0;
		free_size_continuous = GetFreeSizeContinuousFromRear();
		result = recv(socket, buffer + rear, free_size_continuous, 0);
		if (result == SOCKET_ERROR)
		{
			result = WSAGetLastError();
			if (result == 10035) return true; // 읽을 데이터가 없음.
			printf("failed to receive.\n");
			return false;
		}

		rear += result;
		return true;
	}
}

bool RingBuffer::Read(char* dest, uint _length)
{
	uint occupied_size = GetOccupiedSize();

	uint length = _length < occupied_size ? _length : occupied_size;

	uint occupied_size_continouous = GetOccupiedSizeContinuousFromFront();

	if (length == occupied_size_continouous)
	{
		//std::string sub_str(buffer[front], buffer[front + length]);
		memcpy(dest, buffer + front, length);
		front = ((front + length) % real_buffer_size);
		return true;
	}
	else if (length < occupied_size_continouous)
	{
		//std::string sub_str(buffer[front], buffer[front + length]);
		memcpy(dest, buffer + front, length);
		front += length;
		return true;
	}
	else if (occupied_size_continouous < length)
	{
		//std::string sub_str_front(buffer[front], buffer[front + occupied_size_continouous]);
		memcpy(dest, buffer + front, occupied_size_continouous);
		length -= occupied_size_continouous;
		//std::string sub_str_back(buffer[0], buffer[length]);
		memcpy(dest + occupied_size_continouous, buffer, length);
		front = length;
		return true;
	}
}

bool RingBuffer::Peek(char* dest, uint _length)
{
	uint occupied_size = GetOccupiedSize();

	uint length = _length < occupied_size ? _length : occupied_size;

	uint occupied_size_continouous = GetOccupiedSizeContinuousFromFront();

	if (length == occupied_size_continouous)
	{
		//std::string sub_str(buffer[front], buffer[front + length]);
		memcpy(dest, buffer + front, length);
		return true;
	}
	else if (length < occupied_size_continouous)
	{
		//std::string sub_str(buffer[front], buffer[front + length]);
		memcpy(dest, buffer + front, length);
		return true;
	}
	else if (occupied_size_continouous < length)
	{
		//std::string sub_str_front(buffer[front], buffer[front + occupied_size_continouous]);
		memcpy(dest, buffer + front, occupied_size_continouous);
		length -= occupied_size_continouous;
		//std::string sub_str_back(buffer[0], buffer[length]);
		memcpy(dest + occupied_size_continouous, buffer, length);
		return true;
	}
}

TCPServer::TCPServer(const uint port) : port(port)

		return;

	listen_socket = socket(AF_INET, SOCK_STREAM, IPPROTO_TCP);
	if (listen_socket == INVALID_SOCKET)
	{
		result = WSAGetLastError();
		Log("Failed to create socket. (error code " + std::to_string(result) + ")", LogType::Error);

	/*if (modeBlocking) socketType = 0;

		return;

	server_address.sin_family = AF_INET;
	server_address.sin_port = htons(port);
	server_address.sin_addr.S_un.S_addr = htonl(INADDR_ANY);
	result = bind(listen_socket, (SOCKADDR*)&server_address, sizeof(server_address));
	if (result == SOCKET_ERROR)
	{
		result = WSAGetLastError();
		Log("Failed to bind sockaddr to socket. (error code " + std::to_string(result) + ")", LogType::Error);
		return;
	}


	result = listen(listen_socket, SOMAXCONN);
	if (result == SOCKET_ERROR)
	{
		result = WSAGetLastError();
		Log("Failed to convert listen socket into passive socket. (error code " + std::to_string(result) + ")", LogType::Error);
		return;
	}


	listen_event = WSACreateEvent();
	if (listen_event == WSA_INVALID_EVENT)
	{
		Log("Failed to create listen event.", LogType::Error);
		return;
	}
	result = WSAEventSelect(listen_socket, listen_event, FD_ACCEPT | FD_CLOSE);
	if (result == SOCKET_ERROR)
	{
		result = WSAGetLastError();
		Log("Failed to bind listen event to listen socket. (error code " + std::to_string(result) + ")", LogType::Error);
		return;
	}


	RegisterSocketAndEvent(listen_socket, listen_event);


	prev_time = std::chrono::system_clock::now();


	Log("TCP server running...");
}

WSAEVENT TCPServer::RegisterSocketAndEvent(int clientIdx)
{
	if (clientIdx >= WSA_MAXIMUM_WAIT_EVENTS)
	{
		Log("Unable to create a new connection because there are too many connections.", LogType::Error);
		return nullptr;
	}

	WSAEVENT event = WSACreateEvent();
	events[clientIdx] = event;
	if (events[clientIdx] == WSA_INVALID_EVENT)
	{
		Log("Failed to create client event.", LogType::Error);
		return nullptr;
	}

	elapsed_time[clientIdx] = std::chrono::duration<float>::zero();
	receive_buffer[clientIdx] = new RingBuffer(buffer_size);

	++socket_count;

	Log("New client registered. (handle " + std::to_string((uint)sockets[clientIdx]) + ")");
	return event;
}

void TCPServer::RegisterSocketAndEvent(SOCKET socket, WSAEVENT event)
{
	if (socket_count >= WSA_MAXIMUM_WAIT_EVENTS)
	{
		Log("Too many connections. :: No more connections can be made.", LogType::Error);
		return;
	}

	sockets[socket_count] = socket;
	events[socket_count] = event;
	elapsed_time[socket_count] = std::chrono::duration<float>::zero();
	receive_buffer[socket_count] = new RingBuffer(buffer_size);

	++socket_count;

	Log("Event registered.");
}

void TCPServer::RemoveSocketAndEvent(int index)
{
	if (index >= socket_count) return;

	Log("Client disconnected. (handle " + std::to_string((uint)sockets[index]) + ")");

	if (names[index].empty() == false)
	{
		Broadcast(names[index] + "님이 퇴장하셨습니다.", 0);
	}

	closesocket(sockets[index]);

	bool result = WSACloseEvent(events[index]);
	if (result == false)
	{
		Log("Failed to delete socket information.", LogType::Error);
		return;
	}


	sockets[index] = NULL;
	events[index] = NULL;
	names[index] = "";
	delete receive_buffer[index];

	--socket_count;

	for (int i = index; i < socket_count; ++i)
	{
		names[i] = names[i + 1];
		sockets[i] = sockets[i + 1];
		events[i] = events[i + 1];
		elapsed_time[i] = elapsed_time[i + 1];
		receive_buffer[i] = receive_buffer[i + 1];
	}
}

void TCPServer::UpdateTime()
{
	std::chrono::system_clock::time_point cur_time = std::chrono::system_clock::now();
	std::chrono::duration<float> elapsed = cur_time - prev_time;
	prev_time = cur_time;

	for (int i = 0; i < socket_count; ++i)
	{
		elapsed_time[i] += elapsed;
	}
}

void TCPServer::Update()
{
	UpdateTime();

	int eventIdx{ 0 };
	// WinSock 객체 내부에 상태 이벤트 큐에 상태 객체가 가져야 할 상태를 순차적으로 저장한다. WSAWaitForMultipleEvents는 이벤트 객체 배열을 받아 각 이벤트 객체의 상태 신호를 체크하며, 한 번 신호를 체크했다면 해당 이벤트 객체는 큐에 있는 다음 상태 신호로 변경된다. WinSock은 고정 크기의 상태 이벤트 큐를 사용하므로 큐가 가득차면 신호가 누락될 수 있다. 이 때는 에러가 발생하므로 에러 핸들링이 중요하다.
	int result = WSAWaitForMultipleEvents(socket_count, events, false, wait_time, false);
	if (result == WSA_WAIT_TIMEOUT)
	{
		return;
	}
	else if (result == WSA_WAIT_FAILED)
	{
		result = WSAGetLastError();
		Log("Failed to wait events. (error code " + std::to_string(result) + ")", LogType::Error);
		return;
	}

	eventIdx = result - WSA_WAIT_EVENT_0;
	elapsed_time[eventIdx] = std::chrono::duration<float>::zero();

	result = WSAEnumNetworkEvents(sockets[eventIdx], events[eventIdx], &network_event);
	if (result == SOCKET_ERROR)
	{
		result = WSAGetLastError();
		Log("Failed to check event. (error code " + std::to_string(result) + ")", LogType::Error);
		return;
	}


	// 리슨 소켓 전용
	if (network_event.lNetworkEvents & FD_ACCEPT)
	{
		if (network_event.iErrorCode[FD_ACCEPT_BIT] != 0)
		{
			Log("Failed to accept client. (error code " + std::to_string(network_event.iErrorCode[FD_ACCEPT_BIT]) + ")", LogType::Error);
			return;
		}

		Accept();
	}
	else if (network_event.lNetworkEvents & FD_CLOSE)
	{
		if (network_event.iErrorCode[FD_CLOSE_BIT] != 0)
		{
			Log("Failed to disconnect properly. (error code " + std::to_string(network_event.iErrorCode[FD_READ_BIT]) + ")", LogType::Error);
			Close(eventIdx);
			return;
		}

		Close(eventIdx);
	}


	// 클라이언트 소켓 전용
	else if (network_event.lNetworkEvents & FD_READ)
	{
		if (network_event.iErrorCode[FD_READ_BIT] != 0)
		{
			Log("Failed to receive data. (error code " + std::to_string(network_event.iErrorCode[FD_READ_BIT]) + ")", LogType::Error);
			return;
		}

		Receive(eventIdx);

		// 임시 // 나중에 받는 놈 / 읽는 놈 스레드 구분
		ReadAll(eventIdx);
	}
	/*else if (networkEvents.lNetworkEvents & FD_WRITE) // 이걸로 제대로 전송이 됐는지 체크??
	{
		if (networkEvents.iErrorCode[FD_WRITE_BIT] != 0)
		{
			Log("Failed to write data. (error code " + std::to_string(network_event.iErrorCode[FD_WRITE_BIT]) + ")", LogType::Error);
			return;
		}
	}*/
}


void TCPServer::Accept()
{
	int new_client_idx = socket_count;
	
	sockets[new_client_idx] = accept(listen_socket, NULL, NULL);
	if (sockets[new_client_idx] == SOCKET_ERROR)
	{
		int result = WSAGetLastError();
		if (result == 10035) return;

		Log("Failed to accept connection. (error code " + std::to_string(result) + ")", LogType::Error);
		return;
	}

	if (new_client_idx >= WSA_MAXIMUM_WAIT_EVENTS)
	{
		Log("Too many connections. :: No more connections can be made.", LogType::Error);
		closesocket(sockets[new_client_idx]);
		return;
	}

	WSAEVENT event = RegisterSocketAndEvent(new_client_idx);

	int result = WSAEventSelect(sockets[new_client_idx], event, FD_READ | FD_WRITE | FD_CLOSE);
	if (result == SOCKET_ERROR)
	{
		int result = WSAGetLastError();
		Log("Failed to select event. (error code " + std::to_string(result) + ")", LogType::Error);
		return;
	}

	Log("Client connected. (handle " + std::to_string((uint)sockets[new_client_idx]) + ")");
}

bool TCPServer::Receive(int clientIdx)
{
	SOCKET socket = sockets[clientIdx];

	receive_buffer[clientIdx]->Receive(socket);

	ReadAll(clientIdx);

	return true;

bool TCPServer::ReadAll(int clientIdx)
{
	for (int i = 0; i < 4; ++i) // 한 스레드의 1회 시행당 최대 4개의 메시지 처리
	{
		RingBuffer* recvBuffer = receive_buffer[clientIdx];
		uint header_size = sizeof(DGHeader);


		if (recvBuffer->GetOccupiedSize() < header_size) return true;


		char headerByte[sizeof(DGHeader)];
		recvBuffer->Peek(headerByte, header_size);


		DGHeader header;
		memcpy(&header, headerByte, sizeof(DGHeader));


		if (recvBuffer->GetOccupiedSize() < header_size + header.byte) return true;


		recvBuffer->Read(headerByte, header_size);
		recvBuffer->Read(listen_buffer, header.byte);
		listen_buffer[header.byte] = '\0';


		if (header.type == DGHeader::Type::Message)
		{
			Log("Receive message from handle " + std::to_string((uint)sockets[clientIdx]) + ": " + listen_buffer);
			Broadcast(listen_buffer, clientIdx);
		}
		else if (header.type == DGHeader::Type::Inform)
		{
			Log("Receive inform from handle " + std::to_string((uint)sockets[clientIdx]) + ": " + listen_buffer);
			InterpretInformCommand(clientIdx, listen_buffer);
		}
		else if (header.type == DGHeader::Type::Join)
		{
			Log("Handle " + std::to_string((uint)sockets[clientIdx]) + " has joined server.");
			Log("Set nickname of handle " + std::to_string((uint)sockets[clientIdx]) + " to " + listen_buffer);
			names[clientIdx] = listen_buffer;
			Broadcast(names[clientIdx] + "님이 서버에 접속하셨습니다.", 0);
		}

		return true;
	}
}

void TCPServer::Send(int clientIdx, std::string text)
{
	DGHeader header;
	header.type = DGHeader::Type::Message;
	header.byte = text.length();

	char headerByte[sizeof(DGHeader)];
	memcpy(&headerByte, &header, sizeof(DGHeader));

	
	// 헤더 전송
	int result = send(sockets[clientIdx], headerByte, sizeof(DGHeader), 0);

	// send의 len에는 널 문자를 제외한 길이를 넣어야 함
	result = send(sockets[clientIdx], text.c_str(), text.length(), 0);
	if (result == SOCKET_ERROR)
	{
		result = WSAGetLastError();
		Log("Failed to send message to " + std::to_string((uint)sockets[clientIdx]) + " (error code " + std::to_string(result) + ")", LogType::Error);
		return;
	}
	else
	{
		Log("Sent message to" + std::to_string((uint)sockets[clientIdx]) + ": " + text);
		return;
	}
}

void TCPServer::Broadcast(std::string text, uint subject)
{
	if (subject == 0) // 서버
	{
		
	}
	else if (subject > 0 && subject < socket_count) // 클라
	{
		text = "[" + GetCurrentTimeFormatted() + "][" + names[subject] + "] " + text;
	}
	else
	{
		return;
	}
	
	for (int i = 1; i < socket_count; ++i)
	{

}

void TCPServer::DisconnectWithInactiveClients(uint seconds)
{
	std::chrono::seconds sec(seconds);
	
	for (int i = socket_count - 1; i >= 1; --i)
	{
		if (elapsed_time[i] >= sec)
		{
			RemoveSocketAndEvent(i);
		}
	}
}

void TCPServer::InterpretInformCommand(int clientIdx, std::string command)
{
	if (command == "/help" || command == "/?")
	{
		Send(clientIdx, "[도움말] 명령어 목록");
		Send(clientIdx, "/help, /? - 명령어 목록 출력");
		Send(clientIdx, "/set_nickname {name} - 닉네임 {name}으로 변경");
		Send(clientIdx, "/kick {name} - {name} 참여자 강퇴");
	}
	else if (command.substr(0, 14) == "/set_nickname ")
	{
		std::string new_name = command.substr(14);
		if (new_name.length() == 0) return;
		if (new_name.length() > 14)
		{
			Send(clientIdx, "변경하려는 닉네임이 너무 깁니다.");
			return;
		}

		Broadcast(names[clientIdx] + "님이 닉네임을 " + new_name + "으로 변경하셨습니다.", 0);
		names[clientIdx] = new_name;
	}
	else if (command.substr(0, 6) == "/kick ")
	{
		std::string target = command.substr(6);
		if (target.length() == 0) return;

		for (int i = 0; i < socket_count; ++i)
		{
			if (names[i] == target)
			{
				Broadcast(names[clientIdx] + "님이 " + target + "님을 강퇴하셨습니다.", 0);
				RemoveSocketAndEvent(i);
				return;
			}
		}
	}
}

void CLKJCHATDlg::Read()
{
	while (true)
	{
		uint header_size = sizeof(DGHeader);


		if (buffer->GetOccupiedSize() < header_size) return;


		char headerByte[sizeof(DGHeader)];
		buffer->Peek(headerByte, header_size);


		DGHeader header;
		memcpy(&header, headerByte, sizeof(DGHeader));


		if (buffer->GetOccupiedSize() < header_size + header.byte) return;


		buffer->Read(headerByte, header_size);
		buffer->Read(listen_buffer, header.byte);
		listen_buffer[header.byte] = '\0';

		InsertLine(listen_buffer);
	}
}

	InsertLine(data);

	SetState(false);

	return 0;
}




BOOL CLKJCHATDlg::PreTranslateMessage(MSG* pMsg)
{
	if (pMsg->message == WM_KEYDOWN && (pMsg->wParam == VK_ESCAPE || pMsg->wParam == VK_RETURN))
	{
		if (pMsg->wParam == VK_RETURN)
		{
			SendInputText();
		}
		return TRUE;
	}

	return CDialogEx::PreTranslateMessage(pMsg);
}

void CLKJCHATDlg::OnBnClickedConnect()
{
	CString name;
	tUserName.GetWindowText(name);
	userName = name;

	if (name.IsEmpty())
	{
		std::string data = "사용할 수 없는 이름입니다.";
		InsertLine(data);
		return;
	}

	CString ip;
	tServerIP.GetWindowText(ip);

	if (ip.IsEmpty())
	{
		std::string data = "올바르지 않은 IP주소입니다.";
		InsertLine(data);
		return;
	}

	CString _port;
	tServerPort.GetWindowText(_port);

	if (_port.IsEmpty())
	{
		std::string data = "올바르지 않은 포트번호입니다.";
		InsertLine(data);
		return;
	}

	UINT port = _ttoi(_port);

	if (socket) delete socket;
	socket = new CChatSocket;
	socket->Create();
	socket->Connect(_T(ip), port);
}

void CLKJCHATDlg::OnBnClickedSend()
{
	SendInputText();
}

void CLKJCHATDlg::InsertLine(std::string_view text)
{
	txtMain.InsertString(-1, text.data());
	SetVerticalScrollBottom();
}

void CLKJCHATDlg::Send(std::string text, DGHeader::Type type)
{
	DGHeader header;
	header.type = type;
	header.byte = text.length();

	char headerByte[sizeof(DGHeader)];
	memcpy(&headerByte, &header, sizeof(DGHeader));

	socket->Send(headerByte, sizeof(DGHeader));
	socket->Send(text.c_str(), text.length());
	txtInput.SetFocus();
}

void CLKJCHATDlg::SendInputText()
{
	CString str;
	txtInput.GetWindowText(str);

	if (str.IsEmpty()) return;

	std::string text(str);
	txtInput.SetWindowText(_T(""));

	if (text[0] != '/')
	{
		Send(text);
	}
	else if (text[0] == '/')
	{
		Send(text, DGHeader::Type::Inform);
	}
}

void CLKJCHATDlg::SetState(bool isConnected)
{
	if (isConnected)
	{
		tUserName.EnableWindow(false);
		tServerIP.EnableWindow(false);
		tServerPort.EnableWindow(false);
		bConnect.EnableWindow(false);

		txtMain.EnableWindow(true);
		txtInput.EnableWindow(true);
		bSend.EnableWindow(true);
	}
	else
	{
		tUserName.EnableWindow(true);
		tServerIP.EnableWindow(true);
		tServerPort.EnableWindow(true);
		bConnect.EnableWindow(true);

		txtMain.EnableWindow(false);
		txtInput.EnableWindow(false);
		bSend.EnableWindow(false);
	}
}

void CLKJCHATDlg::SetVerticalScrollBottom()
{
	int itemCnt = txtMain.GetCount();
	if (itemCnt > 0)
	{
		txtMain.SetTopIndex(itemCnt - 1);
	}
}
